Vortia 0.13.2 deja Acerca de como en el resto de apps de ingeniería de Nodalia.

*Vortia 0.13.2 makes About the same as in the other Nodalia engineering apps.*

## Español

### Correcciones
- **Acerca de** es la página común de Nodalia con el aspecto de la suite de ingeniería: icono, versión, qué es Vortia, la suite a la que pertenece, enlaces (página, GitHub y avisar de un fallo) y la licencia, en lugar de una ventana de texto suelto.

## English

### Fixes
- **About** is the shared Nodalia page in the engineering suite's look: icon, version, what Vortia is, the suite it belongs to, links (page, GitHub and report an issue) and the licence, instead of a plain text window.
